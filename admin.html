Conectar la aplicación

Para poder publicar obras, esta aplicación necesita una llave de acceso de GitHub. Se pide una sola vez y queda guardada en este teléfono.

  1. Entrá a github.com → llave nueva
  2. En Repository access elegí Only select repositories → suyapabandy-oss/galeria
  3. En Permissions → Repository permissions → Contents, poné Read and write
  4. Generá la llave y pegala aquí abajo

Elegí una llave que solo tenga permiso sobre este repositorio. Así, aunque se filtre, nadie puede tocar el resto de tu cuenta.
